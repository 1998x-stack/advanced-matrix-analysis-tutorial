CHAPTER 21 / ADVANCED MATRIX ANALYSIS

稀疏表示与压缩感知：ℓ1 凸松弛与 RIP

欠定方程 y=Ax（m≪n）通常有无穷多解。但当未知向量稀疏时，可以用凸的 ℓ₁ 问题代替 NP 难的 ℓ₀ 问题。本文说明这一替换成立的条件与代价。

01 / 欠定系统为何能恢复稀疏解？

设 A∈R^{m×n}、m≪n，只有观测 y=Ax。未知量多于方程，通解是一条高维仿射子空间。但若真实 x 最多有 k 个非零元（k-稀疏），则解被“稀疏先验”钉住：满足 Ax=y 的稀疏解通常唯一。问题在于——如何高效地找到它。

稀疏性用 ℓ₀ 伪范数刻画：‖x‖₀ 是非零元的个数。k-稀疏指 ‖x‖₀≤k。最直接的提法是

minx‖x‖0s.t.Ax=y21.1

ℓ₀ 极小化是 NP 难的：它等价于在 n 列中枚举非零位置组合。压缩感知的关键是用凸的 ℓ₁ 范数替代 ℓ₀，在测度矩阵满足一定条件时两者给出同一个解。

对象与前提： 本章默认 A 为实矩阵，y 为无噪声观测。无噪声下是等式约束；有噪声时应改为带容差的 ‖Ax−y‖₂≤ε 或正则化形式（LASSO）。

02 / ℓ0 到 ℓ1 的凸松弛

把 ℓ₀ 换成 ℓ₁，问题变为凸优化：

minx‖x‖1s.t.Ax=y21.2

几何直觉见图：ℓ₁ 球的“角”落在坐标轴上，等值面沿坐标方向更“便宜”，因此最优解常在少数坐标上集中能量；ℓ₂ 球光滑旋转对称，解一般各分量都非零。ℓ₁ 是 ℓ₀ 在单位球上的凸包，这是它能诱导稀疏的结构性原因。

等价不是无条件： 式 21.1 与 21.2 给出同一解，需要 A 满足 RIP（下一节）或其它可识别条件。对任意 A，ℓ₁ 解未必等于最稀疏解。

03 / 受限等距性质 RIP

A 的 k-阶受限等距性质要求它在所有 k-稀疏向量上近似保持欧氏长度：

(1−δk)‖x‖22≤‖Ax‖22≤(1+δk)‖x‖2221.3

对所有 k-稀疏 x 成立，δ_k∈(0,1) 称为 k-阶受限等距常数。RIP 等价于 A 的任意 k 列近似正交。一个基本结论是：若 δ_{2k}<√2−1，则 ℓ₁ 极小化的唯一解恰等于 ℓ₀ 极小化的解。实践中 Gaussian 随机矩阵、部分随机 Fourier 矩阵以高概率满足该条件。

边界： RIP 是充分条件而非必要。某些不满足 RIP 的矩阵仍可恢复稀疏信号，只是缺少统一的保证。反之，当列间高度相干（例如字典含近共线原子）时，ℓ₁ 与 ℓ₀ 可以给出完全不同的解。

04 / 稀疏编码算法

三类常用方法：贪婪（OMP）、凸正则（LASSO）、近端迭代（ISTA/FISTA）。

正交匹配追踪（OMP）：每步选出与残差最相关的列 i_t=argmax_i|⟨r_{t−1},A_i⟩|，把它加入支撑集，用最小二乘在支撑集上更新系数，再更新残差，直到残差足够小或达到 k。简单快速，但不保证全局最优。

LASSO 是 ℓ₁ 正则化的最小二乘：

minx12‖Ax−y‖22+λ‖x‖121.4

λ 控制稀疏度：λ 越大，越多分量被精确置零。LASSO 是凸的，可用坐标下降高效求解。

ISTA 用近端梯度迭代，其中 S_α(z)=sign(z)max(|z|−α,0) 是软阈值：

xk+1=Sλt(xk−tAT(Axk−y))21.5

FISTA 在 ISTA 上叠加 Nesterov 动量，把目标值的收敛速率由 O(1/k) 改进为 O(1/k²)，代价是每步多一次外推。

05 / 矩阵补全与鲁棒 PCA

把稀疏从向量推广到矩阵的“秩”：已知 M∈R^{m×n} 在观测集 Ω 上的元素，要补全整个矩阵。除非 M 低秩，否则不可能；核范数 ‖X‖_*（奇异值之和）正是秩的凸松弛，与 ℓ₁ 之于 ℓ₀ 完全平行：

minX‖X‖*s.t.Xij=Mij,(i,j)∈Ω21.6

在“低秩 + 奇异向量与标准基非相干”的前提下，只需 O(r(m+n)log²(m+n)) 个观测即可高概率精确恢复秩 r 的矩阵，远少于总元素数 mn（Candès–Recht）。

鲁棒 PCA把观测矩阵分解为低秩部分 L 与稀疏部分 S，用于抗离群点的主成分估计（主成分追踪，PCP）：

minL,S‖L‖*+λ‖S‖1s.t.L+S=M21.7

式 21.7 可用 ADMM 求解：L 子问题是奇异值软阈值，S 子问题是元素软阈值——与第 17 章的近端框架一致。

常见误区： 核范数最小化并不“直接最小化秩”，它只是秩的凸代理。当奇异值谱衰减很慢，或观测模式与奇异向量相干时，补全会失败。

06 / 可复算算例：ℓ1 与 ℓ2 的稀疏性差别

下面只用 Python 标准库，对比同一标量问题上 ℓ₁ 与 ℓ₂ 正则化的解：ℓ₁ 可把解精确压到 0，ℓ₂ 只会按比例缩小。

def l1(y, lam): return max(y - lam, 0.0) - max(-y - lam, 0.0)   # argmin 0.5*(x-y)^2 + lam*|x|
def l2(y, lam): return y / (1 + 2*lam)                          # argmin 0.5*(x-y)^2 + lam*x^2
lam = 0.5
for y in (0.3, 2.0):
    print("y=%.1f: l1=%.4f  l2=%.4f" % (y, l1(y, lam), l2(y, lam)))

预期输出：y=0.3: l1=0.0000 l2=0.1500 与 y=2.0: l1=1.5000 l2=1.0000。核对要点： y=0.3<λ=0.5 时 ℓ₁ 解恰为 0（稀疏），ℓ₂ 解仍为 0.15（非零）。失败模式： 若对 ℓ₁ 使用普通梯度下降而不做软阈值，解会停在很小的非零值，得不到精确的稀疏支撑集。

λ=0.30（固定 y=0.3）：ℓ₁ 解=0.0000，ℓ₂ 解=0.1875。

该控件对固定 y=0.3 并给出两种正则化的解：当 λ≥y=0.3 时 ℓ₁ 解被精确置零，而 ℓ₂ 解始终为正（0.3/(1+2λ)）。它直观说明“凸但光滑”的 ℓ₂ 不产生稀疏。默认状态无需脚本即可读出；键盘方向键可调 λ。
