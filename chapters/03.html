CHAPTER 03 / ADVANCED MATRIX ANALYSIS

特殊矩阵：正交、对称与正定

同样是方阵，为什么旋转保持长度、正定矩阵保证能量大于零？从几何、二次型与谱结构辨认特殊矩阵。

01 / 什么样的矩阵能预测自己的行为？

很多矩阵可由其结构直接看出计算性质。旋转矩阵保持欧氏长度；对称正定矩阵保证二次型严格为正；上三角矩阵的特征值就在对角线上。区别在于：有的结构控制几何，有的控制谱，还有的控制计算是否稳定。

图中正定例子选 S=diag(2,1)，因此圆被拉为椭圆；一般对称正定矩阵可能在某个旋转后的正交基下呈现这一形式。

02 / 用一个性质识别一个矩阵家族

类型定义（实数域）可立即推出
对角 D非对角元素为 0特征值是对角元；逐方向伸缩
上三角 U主对角线下为 0det(U) 为对角元之积
对称 SSᵀ=S实特征值、正交特征基
正交 QQᵀQ=I长度/内积不变，|det(Q)|=1
正定 SS=Sᵀ，xᵀSx>0特征值全正；Cholesky 分解存在

在复数域中，对称性常须改为 Hermitian（共轭转置不变），正交矩阵的自然对应物是酉矩阵 U*U=I。不要把普通转置与共轭转置混用。

03 / 为什么正交变换不会放大误差？

对于实正交矩阵 Q，有 QᵀQ=I。因此任意两个向量的内积都满足 (Qx)ᵀ(Qy)=xᵀy；令 x=y 即得长度不变。这是 QR 分解和许多数值算法倾向于使用正交变换的重要原因之一。

QTQ=I⇒‖Qx‖2=‖x‖23.1

若想让映射既正交又非均匀伸缩，通常做不到：正交矩阵的全部奇异值都等于 1。旋转与反射是其二维典型例子；行列式只能是 +1 或 −1。

04 / 二次型如何刻画正定性？

实对称矩阵 A 正定，当且仅当对任意非零 x 都有 xᵀAx > 0。对于 A=[[2,1],[1,2]]，二次型可直接拆成平方：

x12+x22+(x1+x2)2>03.2

上式在非零向量处严格大于 0，因而 A 正定。另一个等价刻画是全部特征值为正；本例的特征值分别为 3 与 1。正定性使线性方程、二次优化与协方差模型拥有更强的结构。

注意：非对称矩阵即使满足 xᵀAx > 0，在不同定义体系中也未必直接称为“正定矩阵”。本章固定实对称/复 Hermitian 的标准约定。

05 / 一处负号使正定性失效

A = [[2,0],[0,1]]：特征值 2、1；对所有非零 x，xᵀAx > 0。

一项负特征值就足以找到负二次型方向。反过来，有限次采样“看起来全为正”无法证明正定；严格验证需分析所有方向，或计算特征值、Sylvester 判据、成功的 Cholesky 分解等结构性条件。

A = ((2,1),(1,2))
def quadratic(x):
    return sum(x[i]*A[i][j]*x[j] for i in range(2) for j in range(2))
for x in ((1,0),(0,1),(1,-1),(2,-3)):
    assert quadratic(x) > 0
print("sample quadratic values:", [quadratic(x) for x in ((1,0),(1,-1))])

预期输出：sample quadratic values: [2, 2]。这只是算例的抽查；一般性来自上面的平方分解或谱定理。
