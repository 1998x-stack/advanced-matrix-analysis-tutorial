CHAPTER 02 / ADVANCED MATRIX ANALYSIS

线性空间、映射与秩-零化度

从三维数据到二维观测：哪些信息被保留，哪些方向落入核？通过具体映射理解向量空间、基、秩与换基。

01 / 三维输入为什么只留下二维信息？

设一个三维向量是 x=(x₁,x₂,x₃)，而观测系统只返回 (x₁+x₃,x₂+x₃)。输出有两个数，但哪些三维信息被保留下来？哪些不同输入产生同一个观测结果？

A=(101011),A(-1-11)=(00)2.1

三列不独立，但输出恰好能覆盖整个 R²；像的维数是 2，核的维数是 1。丢失的一维，正是输入中无法从观测恢复的方向。

02 / 向量空间不是“箭头的集合”

向量空间是域 F 上带加法和数乘的集合，满足封闭性、结合律、交换律、零元、加法逆元、数乘单位元及两种分配律等公理。它可以是 Rⁿ、多项式空间，也可以是固定大小矩阵的集合。把函数当作向量时，依然可以讨论线性组合、独立性与基。

若 v₁,…,vₖ 张成空间，说明每一个向量都能表示为它们的线性组合；若还线性无关，就构成一组基。有限维空间的不同基可能长得完全不同，但基向量的数量（维数）相同。

常见误区：“两个向量数量相同”不等于“两个向量空间相同”。必须说明标量域、集合与运算规则；R 上的二维空间和 C 上的一维空间不是在同一域上比较的。

03 / 核、像、秩与零化度

对 A∈F^{m×n}，核是使 Ax=0 的全部输入；像是所有可能输出。两者都是子空间。核位于 Fⁿ，像位于 Fᵐ。矩阵的秩定义为像的维数，而零化度是核的维数。

dim(kerA)+rank(A)=n2.2

这是秩-零化度定理。右侧是定义域维数 n，不是输出维数 m。本例中 1+2=3。推广到数据分析，它说明再精巧的算法也不能仅凭 Ax 唯一恢复沿核方向丢失的量，除非再施加额外先验或约束。

另有行空间和左核空间：行空间是 Fⁿ 中由行向量张成的空间；左核是满足 Aᵀy=0 的 Fᵐ 向量集合。在标准欧氏内积下，行空间与核正交；列空间与左核正交。

04 / 换基改变的是坐标，不是映射

考虑同一空间上的线性算子 T。若旧基矩阵与新基矩阵之间满足 V_new = V_old P，并且旧基下矩阵为 A，新基表示为 P⁻¹ A P（要求 P 可逆）。这是相似变换。它保持特征多项式、迹与行列式，但通常改变矩阵元素。

Anew=P-1AoldP2.3

必须强调：上式适用于定义域和值域为同一空间、且在两侧一致换基的线性算子。如果是 Fⁿ→Fᵐ 的一般映射，输入和输出可能采用不同换基矩阵，公式应是 Q⁻¹AP（各自可逆且尺寸匹配）。

05 / 只改一行，秩就变化

A = [[1,0,1],[0,1,1]]：rank(A)=2，nullity(A)=1；零空间由 (-1,-1,1) 张成。

改变行向量之间的线性依赖关系，就改变了矩阵的秩。这里两种矩阵都把三维输入送到二维输出，但第一种有二维像，第二种只保留一维像；秩与矩阵的外形尺寸不是一回事。

def apply(A, x):
    return tuple(sum(a*b for a,b in zip(row,x)) for row in A)
A = ((1,0,1),(0,1,1))
v = (-1,-1,1)
assert apply(A, v) == (0,0)
assert apply(A, (1,0,0)) == (1,0)
assert apply(A, (0,1,0)) == (0,1)
print("nonzero null vector:", v)

预期：nonzero null vector: (-1, -1, 1)。这个断言证明了 v 属于核；核的一维性仍需结合两行独立以及秩-零化度定理推出。
