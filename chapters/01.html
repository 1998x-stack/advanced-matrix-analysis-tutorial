CHAPTER 01 / ADVANCED MATRIX ANALYSIS

矩阵分析导论：从网格变形理解矩阵

为什么面积相同，长度却可能发生巨大变化？以二维变换建立矩阵、秩、谱和条件数之间的第一张概念地图。

01 / 为什么面积没有变化，向量却被拉长？

考虑一个最简单的线性映射：把平面上所有点的横坐标乘以 2，纵坐标乘以 1/2。单位正方形变为宽 2、高 1/2 的矩形；面积仍是 1。但长度为 1 的水平向量变成长度 2，竖直向量却缩短为 1/2。“面积不变”绝不等于“距离不变”。

A=(20012),|det(A)|=11.1

同一个矩阵还有另一个量度：在欧氏范数下，其最大拉伸倍率是 2，最小拉伸倍率是 1/2；因此二范数条件数为 4。行列式、奇异值与条件数回答的是不同问题：体积变化、各方向尺度变化、误差放大风险。

02 / 矩阵的列记录了什么？

线性映射需要两个条件：可加性 T(u+v)=T(u)+T(v) 与齐次性 T(αu)=αT(u)。选定定义域和值域的基后，映射才有矩阵表示。若 A 是 m×n 矩阵，输入 x∈Fⁿ，那么输出 Ax∈Fᵐ。

Ax=Ae1x1+⋯+Aenxn1.2

更直接地写成 Ax = x₁(Ae₁) + … + xₙ(Aeₙ)：第 j 列是第 j 个标准基向量的像。列不独立时，部分输入方向会映射到零，这正是零空间出现的原因。对于一般矩形矩阵，谈“行列式”“特征值”前必须先检查其是否为方阵。

记住： 线性映射与它在特定基下的矩阵不是同一概念。换基会改变坐标；映射本身没有改变。

03 / 从局部方向到复合变换

连续实施两个变换时，右侧矩阵先作用：若 x → Bx → A(Bx)，复合结果是 ABx。一般情况下 AB ≠ BA，这在旋转与非均匀拉伸叠加时尤其明显。

四个最常用的结构性观察分别是：秩揭示保留多少独立方向；核揭示哪些输入被抹去；特征方向揭示哪些方向经作用仍在同一直线上；奇异值揭示欧氏距离被放大或缩小的极端倍率。矩阵分析要把这些观察组织为互相约束的结论，而不是孤立背公式。

04 / 改变伸缩比例，哪些量保持不变？

取 A(t)=diag(t,1/t)，其中 t≥1。两个对角方向的伸缩倍率互为倒数，所以面积始终不变；但对 t>1，最大与最小倍率之间的差距越来越大。

A = diag(2, 0.5)：面积倍率 1；最大长度倍率 2；条件数 4。
κ2(A)=σ1(A)σmin(A)=t21.3

这里使用的是非奇异方阵的 2-范数条件数。对于奇异矩阵，它取无穷大；对于非方阵，广义条件数有额外约定，不应直接套用上式。

05 / 用 15 行代码验证观点

下面只使用 Python 标准库。固定具体矩阵与向量，逐项检查面积倍率、最大伸缩率以及 Ax 的形状，不把有限个测试点误当成普遍证明。

from math import hypot
A = ((2.0, 0.0), (0.0, 0.5))
def apply(x):
    return (A[0][0]*x[0] + A[0][1]*x[1],
            A[1][0]*x[0] + A[1][1]*x[1])
det = A[0][0]*A[1][1] - A[0][1]*A[1][0]
assert det == 1.0
assert apply((1, 0)) == (2.0, 0.0)
assert apply((0, 1)) == (0.0, 0.5)
assert hypot(*apply((1, 0))) == 2.0
print("det =", det, "; condition_2 =", 2 / 0.5)

预期输出：det = 1.0 ; condition_2 = 4.0。真实问题中若矩阵接近奇异，仅看行列式数值大小往往不足以判断稳定性：单位缩放就会改变 det，而条件数在一致尺度缩放下保持不变。
