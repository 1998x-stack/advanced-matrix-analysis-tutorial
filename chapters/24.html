CHAPTER 24 / ADVANCED MATRIX ANALYSIS

CP 分解、Tucker 分解与 HOSVD

矩阵 SVD 把矩阵写成三个因子；张量没有唯一对应的推广，而是分岔为两条路线——追求唯一但秩难算的 CP，与追求灵活但可左乘可逆矩阵而不唯一的 Tucker。HOSVD 给出后者一个廉价起点。

01 / 张量有没有 SVD？

矩阵有 SVD A=UΣVᵀ，奇异值排序后基本唯一，且截断给出最优低秩逼近（Eckart–Young）。张量呢？答案是：没有一个唯一对应的推广。张量分解沿两条不同的路线分岔：一条追求“拆成最少几个秩-1 块”的 CP 分解，一条追求“每个模独立降维”的 Tucker 分解。

先摆出反常的地方。矩阵分解总是不唯一的：A=(AQ)(QᵀB) 对任意可逆 Q 都不改变乘积（正交 Q 则保持两因子的正交性）。而 CP 分解在温和条件下反而是本质唯一的（只差缩放与排列）——这与矩阵形成鲜明对比。另一点差异是秩：矩阵秩有唯一且良定义的概念，张量却至少有两种不同的秩（CP 秩与 Tucker 秩，见第 23 章）。

对象与前提： 本章以 3 阶实张量 T∈R^{I×J×K} 为例，记号沿用第 23 章：模-n 展开 T_(n)、模-n 积 ×_n、Khatri-Rao 积 ⊙、Kronecker 积 ⊗。结论可逐字推到 N 阶；复域需把转置换成共轭转置。

接下来依次交代：CP 的定义与 Kruskal 唯一性条件、求解它的 CP-ALS、Tucker 分解及其与 CP 的关系、计算 Tucker 的 HOSVD，以及一个容易误解的点——截断 HOSVD 并不给出最优低秩张量逼近。

02 / CP 分解与唯一性

CP 分解（CANDECOMP/PARAFAC）把张量写成有限个秩-1 张量之和：

T≈∑r=1Rλrar(1)∘⋯∘ar(N)24.1

其中 ∘ 是外积，a_r^(n)∈R^{I_n} 是第 r 个成分在第 n 模上的因子向量，λ_r 是权重。对 3 阶张量 T∈R^{I×J×K}：

T≈∑r=1Rλrar∘br∘cr24.2

含义很直观：高维数据由 R 个“基本模式”叠加而成，每个模式在各模上各有一个特征方向。当 R 取成 T 的 CP 秩时，这是精确表示（第 23 章）；实践中常取较小的 R 做近似。

唯一性是 CP 最大的卖点。矩阵分解总可左乘可逆矩阵而不改变乘积，但 CP 在温和条件下本质唯一：只差因子列的排列与缩放（各模缩放之积为 1）。Kruskal（1977）给出充分条件：

kA+kB+kC≥2R+224.3

其中 k_A 是因子矩阵 A=[a_1,…,a_R] 的 Kruskal 秩（使得任取 k 列都线性无关的最大 k）。k 比普通矩阵秩更严：普通秩只要求存在一组线性无关列，而 Kruskal 秩要求任意 k 列都线性无关。

边界： 式 24.3 是充分条件而非必要条件；它不能判定“分解不唯一”，只能说“满足则唯一”。当因子矩阵列高度相干时 Kruskal 秩变小，条件更难过。唯一性也不保证算法能找到全局最优——那是下一节的事。

03 / CP-ALS：把非线性问题拆成线性子问题

给定张量 T 与成分数 R，求因子矩阵 A∈R^{I×R}、B∈R^{J×R}、C∈R^{K×R} 使重构误差最小：

minA,B,C‖T−∑r=1Rar∘br∘cr‖F224.4

交替最小二乘（ALS） 每次固定两个因子、求解第三个。固定 B、C 时，借助第 23 章的展开—Khatri-Rao 关系，问题化成线性最小二乘：

minA‖T(1)−A(C⊙B)T‖F224.5
A=T(1)[(C⊙B)T]†24.6

轮换求解 A→B→C，直至重构误差收敛。每次解完常把因子矩阵的列归一化并把范数吸收入 λ，以免列范数无界漂移。

import numpy as np

def khatri_rao(X, Y):                       # (m×R),(n×R) -> (mn×R)
    return np.einsum('ir,jr->ijr', X, Y).reshape(X.shape[0]*Y.shape[0], X.shape[1])

def cp_als(T, R, iters=100, tol=1e-6):
    I, J, K = T.shape
    rng = np.random.default_rng(0)
    A = rng.standard_normal((I, R)); B = rng.standard_normal((J, R)); C = rng.standard_normal((K, R))
    for _ in range(iters):
        A = T.reshape(I, -1) @ np.linalg.pinv(khatri_rao(C, B).T)          # 固定 B,C 解 A
        B = np.transpose(T, (1, 0, 2)).reshape(J, -1) @ np.linalg.pinv(khatri_rao(C, A).T)
        C = np.transpose(T, (2, 0, 1)).reshape(K, -1) @ np.linalg.pinv(khatri_rao(B, A).T)
        if np.linalg.norm(T - np.einsum('ir,jr,kr->ijk', A, B, C)) < tol: break
    return A, B, C
CP-ALS 的三个坑： (1) 只收敛到局部最优，对初值敏感，常用多次随机重启或 HOSVD 做初值；(2) 必须预先指定 R，而 CP 秩是 NP-hard，实践靠肘部法则或交叉验证选 R；(3) 可能出现 退化（degeneracy）：因子列范数趋于无穷而重构误差不降，得不到解。

04 / Tucker 分解：核心张量 + 每模一个因子矩阵

Tucker 分解（Tucker, 1966）把一个张量写成一个核心张量沿各模与因子矩阵的模-n 积：

T=G×1A×2B×3C24.7

逐元素写开，即每个元素由核心张量的元素与三个因子矩阵对应行相乘求和：

tijk≈∑p=1P∑q=1Q∑r=1Rgpqraipbjqckr24.8

可把 Tucker 看成“每个模上各做一次 PCA”：因子矩阵是各模的主子空间，核心张量记录这些子空间之间的多重线性耦合。

  • 若 P=Q=R=1，退化为秩-1 近似（CP 的 R=1 情形）。
  • 若 P=I, Q=J, R=K 且因子矩阵正交，则是一次精确重新参数化（不降维）。
  • 若核心张量 G 非零元只在 p=q=r，即 超对角，则 Tucker 退化为 CP。
CP 与 Tucker 的关系： CP 是 Tucker 的特例（核心张量超对角时）。CP 参数少（R(I+J+K)），Tucker 更灵活但核心张量稠密，参数为 PQR+IP+JQ+KR。Tucker 的因子矩阵不唯一：对任一因子矩阵左乘可逆矩阵、同时对核心相应模做反向变换，乘积不变。

05 / HOSVD：对每个模展开做 SVD

高阶 SVD（HOSVD，De Lathauwer 等，2000）给出了一个廉价、稳定、但非最优的 Tucker 起点：对每个模展开矩阵各做一次 SVD，取前几个左奇异向量作为因子矩阵。

T(n)=UnΣnVnT⟹A(n)=Un[:,1:Rn]24.9
G=T×1A(1)T×2⋯×NA(N)T24.10
  1. 对每个 n 计算模-n 展开 T_(n)；
  2. 做 SVD T_(n)=U_n Σ_n V_nᵀ；
  3. 取前 R_n 个左奇异向量得因子矩阵 A^(n)∈R^{I_n×R_n}；
  4. 按式 24.10 投影得核心张量 G。
import numpy as np

def hosvd(T, ranks):
    I, J, K = T.shape; P, Q, R = ranks
    A = np.linalg.svd(T.reshape(I, -1), full_matrices=False)[0][:, :P]
    B = np.linalg.svd(np.transpose(T, (1, 0, 2)).reshape(J, -1), full_matrices=False)[0][:, :Q]
    C = np.linalg.svd(np.transpose(T, (2, 0, 1)).reshape(K, -1), full_matrices=False)[0][:, :R]
    G = np.einsum('ijk,ip,jq,kr->pqr', T, A, B, C)   # 核心张量
    return G, A, B, C
为什么快： HOSVD 只需 N 次矩阵 SVD，无需迭代，且因每个 U_n 正交，因子矩阵天然正交、数值稳定。代价是它不最小化式 24.4 的重构误差（见下节）。

06 / 截断 HOSVD 的局限：它不是最优低秩逼近

矩阵 SVD 截断是最优低秩逼近（Eckart–Young）。很多人以为 HOSVD 同理，这是一个常见误解。截断 HOSVD 的重构为

T~=G×1A×2B×3C24.11

它有误差上界：‖T−T̃‖_F² ≤ Σ_{n} Σ_{i_n>R_n} σ_{i_n}^{(n)2}，即不超过各模丢弃奇异值平方之和——这是“准最优”而非最优。各模独立截断忽略了跨模耦合，所以 HOSVD 通常比真正的 TLS（张量最小二乘）差。实践中用 HOSVD 作初值，再用 Tucker-ALS 迭代微调。

更细致的事实： 与矩阵不同，固定 Tucker 秩 (R₁,R₂,R₃) 的最优逼近可能不存在（de Silva & Lim, 2008）：误差下确界可能无法被任何一个秩受限张量取到。这与 CP 的退化现象同源，是张量优化与矩阵优化的一大分野。

选秩仍可用奇异值谱的“肘部”：对每个模画 Σ_n，单独判断保留多少维。注意不同模的奇异值尺度不同，不能在同一个轴上直接比较。

07 / CP、Tucker 与 HOSVD 对比

三种分解的关键差别（3 阶，T∈R^{I×J×K}）
特性CPTuckerHOSVD
秩概念CP 秩（一个数 R）Tucker 秩（N 元组 (R₁,…)）同 Tucker，由 SVD 截断确定
唯一性满足 Kruskal 条件时本质唯一不唯一（因子矩阵可左乘可逆矩阵）不唯一（但因子矩阵正交）
计算ALS / 优化（可陷局部最优）HOSVD 初值 + ALS 微调每模一次 SVD，无迭代
参数数（3 阶）R(I+J+K)PQR+IP+JQ+KR同 Tucker
逼近质量精确到 CP 秩；优化非凸优于 HOSVD，但最优可能不存在准最优（非最优）
典型用途盲源分离、光谱分析降维、压缩初始化、快速近似
一句话选择： 要可解释与唯一性 → CP；要灵活压缩 → Tucker；要稳定快速的起点 → HOSVD。三者不是互斥，标准流程常是“HOSVD 初始化 + ALS 精化”。

08 / 可复算算例：秩-1 重构与参数对比

用标准库验证一个基本事实：当张量确实是秩-1 时，R=1 的 CP 能精确重构它；同时对比 CP 与 Tucker 的参数数。

a = [1, 2]; b = [1, 0, 1]; c = [2, 1]
T = [[[a[i]*b[j]*c[k] for k in range(2)] for j in range(3)] for i in range(2)]
print("T[0]=", T[0])          # 期望 [[2,1],[0,0],[2,1]]
print("T[1]=", T[1])          # 期望 [[4,2],[0,0],[4,2]]
print("CP R=1 参数:", 1*(2+3+2), " 张量元素:", 2*3*2)

预期输出：T[0]=[[2,1],[0,0],[2,1]]、T[1]=[[4,2],[0,0],[4,2]]、CP R=1 参数: 7 张量元素: 12。核对要点： 秩-1 张量的元素满足 t_ijk=a_i b_j c_k，任意元素都可从三个向量重建；R=1 的 CP 只用 7 个参数就能存下 12 个元素。失败模式： 若把外积写成 a_i c_j b_k（索引错位），得到的是完全不同的张量；若不约束因子范数，λ 与因子存在缩放自由度，解不唯一。

R=2（3×4×5 张量）：CP 参数 24；Tucker 参数（P=Q=R=2）32，相差的核心张量项 PQR=8。

该控件展示参数增长：CP 随 R 线性增长（12R），Tucker 含核心张量项 R³，故同秩下增长更快。默认状态无需脚本即可读出；键盘方向键可调 R。
