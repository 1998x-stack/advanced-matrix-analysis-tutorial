CHAPTER 25 / ADVANCED MATRIX ANALYSIS

张量网络与高级分解：TT、TR 与 HT

一个 10 阶、每维长度为 10 的张量有 10¹⁰ 个元素。张量网络不直接存储它，而是把它拆成一串小张量，用收缩重建。本文交代 Penrose 表示法、TT/TR/HT 三种结构，以及它们为何把指数存储降为线性。

01 / 维数灾难：指数存储从哪里来

一个 d 阶、每维长度都是 n 的张量有 n^d 个元素。取 d=10、n=10：10^{10} 个元素，以 float64 存储需 8×10^{10} 字节≈80 GB。维度一增加，存储量指数爆炸——这就是维数灾难（curse of dimensionality）。

但是许多真实数据并非任意的。相邻维度往往强相关，远处维度只通过中间维度间接影响。如果张量在这种意义下具有低秩结构，就不必存全部 n^d 个元素，而可以用一组小张量及其收缩来表示它——这就是张量网络。

对象与记号： 本章用 d 表示阶（不用 N，以避开上章的多线性秩记号），各维长度 n_1,…,n_d（在例子中取相同 n），T∈R^{n_1×…×n_d}。张量网络是一张图：节点是小张量，边是被求和（收缩）的共享索引。以下三种结构都是同一思想的特殊图形。

本节路线：先给出观察图的规则（Penrose 表示法），再依次交代链式的 TT、闭环的 TR、树式的 HT，最后看它们在“张量化”网络层中的应用。

02 / Penrose 图形表示法

张量网络文献几乎都用Penrose 图形表示法：一个节点代表一个张量，一条边代表一个索引，连接两个节点的边代表对该索引求和（即收缩）。三条规则：

  • 节点： 一个小张量；度数（接出多少条边）等于它的阶。
  • 边： 一个开放边是一个自由索引（张量的一部分）；一条连到另一节点的边是被收缩的索引。
  • 收缩： 沿共享索引求和，结果张量的阶 = 两节点度数之和减去被收缩的边数。

例如矩阵乘法 C=AB 就是两个 2 度节点用一条边相连，结果是 2 度节点；而模-2 积是一个 3 度节点与一个 2 度节点共用一条边：

(T×2U)ijk=∑j′tij′kujj′25.1
为什么有用： 当收缩层数变多，代数公式会变得难以核对，而图一画就能看出哪些索引被求和、哪些留给结果。收缩的顺序会显著影响计算量（同图不同收缩次序），这是张量网络计算的工程核心问题之一。

03 / Tensor-Train：链式低秩

Tensor-Train（TT）又称矩阵积态（Matrix Product State, MPS）。它把高阶张量表示为一串 3 阶核心（TT-cores）的收缩：

T(i1,…,id)≈∑α1⋯∑αd−1G1(α0,i1,α1)⋯Gd(αd−1,id,αd)25.2

每个核心 G_k∈R^{r_{k−1}×n_k×r_k}，r_1,…,r_{d−1} 是 TT 秩，边界条件 r_0=r_d=1（首尾核心退化为矩阵）。图形上就是一条直线上 d 个节点依次相连，像火车车厢。

存储量因此从指数降为线性：原始 O(n^d)，TT 为 O(d·n·r²)（r=max r_k）。以 d=10、n=10、r=5 为例：原始 10^{10} 个参数，TT 只需 10×10×25=2500 个，减少约 400 万倍——代价是它只是近似，且当真实 TT 秩很大时优势消失。

来源： TT 分解由 Oseledets（2011）系统提出；物理中的矩阵积态与密度矩阵重整化群（White, 1992）早已使用同构思想。它们是同一数学结构在不同社区的名称。

04 / Tensor-Ring：把链首尾相连

Tensor-Ring（TR）把 TT 的链两端连接成环，边界条件由 r_0=r_d=1 改为 r_0=r_d（首尾秩相等并相连）：

T(i1,…,id)≈∑α1,…,αdG1(αd,i1,α1)G2(α1,i2,α2)⋯Gd(αd−1,id,αd)25.3

与 TT 相比，主要差别有两点：

  • 边界更均衡： TT 两端的核心只有两个索引（表达能力弱），TR 中所有核心都是完整的 3 阶张量，随维度排列的边界效应减弱。
  • 表达能力： 固定秩上限时，一般认为 TR 能用较少参数达到相近的逼近质量，但这依赖具体数据，不是普遍保证。

代价是收缩与优化更复杂：环上的收缩不如链上直观，求导也需处理循环依赖。

05 / Hierarchical Tucker：二叉树组织维度

层级 Tucker（HT）又称树状张量网络（TTN）。它不做链式分组，而是递归地把维度二分：每次把两组维度合并，在上层产生一个新的核心张量，直到根部。结果是叶节点为原始维度的二叉树。

每个内部节点 t 有一个核心 B_t，其连接上层与两个子节点；节点秩由对应子张量沿该分裂的矩阵秩定义：

rt=rank(T(t)t)25.4

存储复杂度同为 O(d·n·r²)。相较 TT，HT 的优势在于能自然地表达层次化的维度分组：图像里相邻像素组成局部区域、区域组成图像块、图像块组成整幅图，这与二叉树的层级结构天然对应；而 TT 要求把维度排成一条链，分组方式是“线性”的。

选择指南： 维度有顺序结构（时间、序列）→ TT 或 TR；维度有层次/分组结构（图像、多尺度）→ HT；不确定 → 从 TT 开始，它的算法最简单、最成熟。

07 / 张量化神经网络层

一个全连接层就是矩阵乘法 y=Wx，W∈R^{M×N}，参数量 MN。当 M、N 达到上万时，仅一层就有上亿参数。张量化的思路是：把权重矩阵的维度重排成一个 d 阶张量，再做 TT 分解，用 TT 核心代替原矩阵：

W（M×N）→ reshape 为 n₁×…×n_d → TT 分解 → 参数量 O(d·n·r²)

前向传播变成一系列小张量的收缩，比稠密矩阵乘法便宜。Novikov 等人（2015）的开创性工作《Tensorizing Neural Networks》展示了这条路：在多个网络上用 TT 层替换全连接层，报告了数量级的参数压缩与较小的精度损失（具体数值以原文实验表为准，此处不转述具体百分点）。

为什么可能有效： 若权重矩阵的“本质秩”远低于 min(M,N)，则其中大量自由度冗余，低秩张量结构能保留主要信息。但若权重接近满秩，TT 会产生明显误差——压缩率与精度是一对取舍，不存在免费午餐。

同一思路也被用到卷积核、循环网络与注意力投影矩阵上；是否奏效取决于对应张量的实际低秩程度，需逐层验证。

08 / 可复算算例：TT 的存储节省

用标准库直接算出“原始 vs TT”的参数比，核对指数与线性的差别。

n, d, r = 10, 10, 5          # 每维长度、阶数、最大 TT 秩
original = n ** d            # 原始参数（指数）
tt = d * n * r * r           # TT 参数（线性于 d）
print("原始=%d  TT=%d  比值=%.0f" % (original, tt, original / tt))

预期输出：原始=10000000000 TT=2500 比值=4000000。核对要点： 原始参数随 d 按 n^d 增长，TT 参数按 d·n·r² 线性增长；压缩比 = n^d/(d n r²)。失败模式： 若真实 TT 秩需达到 n^{d/2} 量级，存储会回到指数级，压缩失效；若把 r² 误写成 r，会高估压缩比约 r 倍。

d=10，n=10，r=5：原始 1.0e+10 个参数，TT 2500 个，比值 ≈ 4000000。

该控件展示：阶数每加 1，原始参数乘 10，而 TT 参数只加 250。d 越大，线性与指数的差距越显著。默认状态无需脚本即可读出；键盘方向键可调 d。
