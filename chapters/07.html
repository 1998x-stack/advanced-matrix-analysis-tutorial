CHAPTER 07 / ADVANCED MATRIX ANALYSIS

矩阵函数与矩阵指数：动力系统的时间流

从微分方程 x′=Ax 到 e^{tA}，解释矩阵级数、Jordan 多项式因子、指数律和稳定计算的边界。

01 / 一个矩阵怎样推动连续时间系统？

设系统状态为 x(t)∈Rⁿ，且变化率由当前状态线性决定：x′(t)=Ax(t)。我们寻找随时间运行的变换 T(t)，满足从任意初始状态出发都能得到解。矩阵指数 e^{tA} 就是这个线性时间流。它并不是对每个矩阵元素分别取指数。

etA=∑k=0∞tkAkk!(7.1)

幂级数对每个有限维实或复方阵、每个有限 t 都收敛。逐项求导可得 d(e^{tA})/dt=Ae^{tA}；当 t=0 时有 e⁰=I。因此 x(t)=e^{tA}x₀ 确实满足初值问题。

02 / 为什么 Jordan 块引出 t·e^{λt}？

对 J=2I+N 且 N²=0，由于 I 与 N 交换，可以写成 e^{tJ}=e^{2t}e^{tN}。对 N 的指数只剩下两项，于是得到：

etJ=e2t(I+tN)(7.2)

以初始状态 x₀=(0,1) 为例，输出就是 x(t)=e^{2t}(t,1)。因此广义特征向量不仅按 e^{2t} 增长，还与特征方向耦合，形成 t e^{2t} 项；更长的 Jordan 链会带来更高次 t 的幂。

t=1：e²(t,1)≈(7.389,7.389)。

03 / 一般矩阵函数怎么定义？

当 A 可对角化时，若 A=VΛV⁻¹，且标量函数 f 在谱上有定义，则可用 f(A)=V f(Λ)V⁻¹。例如 f(z)=e^z 就把每一个对角特征值变成对应的指数值。

f(A)=Vf(Λ)V−1(7.3)

不能对角化时不能假装 f 逐个只作用于特征值：Jordan 块还需要导数信息。例如对 A=λI+N、N²=0，若 f 在 λ 附近解析，则有 f(A)=f(λ)I+f′(λ)N。矩阵平方根和矩阵对数还涉及存在性、分支选择；不能认为每个实矩阵都有实矩阵对数。

04 / Cayley–Hamilton 如何减少高次幂？

对方阵 A，令 p_A(z)=det(zI−A)，Cayley–Hamilton 定理指出 p_A(A)=0。这意味着 A 的高次幂可以化简为次数小于 n 的多项式。对 A=[[1,1],[0,1]]，(A−I)²=0，所以 A²−2A+I=0。

这一结论提供矩阵函数的结构性定义途径，但不意味着数值上总应该先计算特征多项式。对高维或病态问题，求特征多项式的系数并展开可能损失显著精度。

05 / 指数律为什么不能照搬到非交换矩阵？

同一个 A 的时间流满足 e^{(s+t)A}=e^{sA}e^{tA}；一般两个不同矩阵的 e^{A+B}=e^Ae^B 却不一定成立。只有满足 AB=BA 等相应条件时，才能安全使用这个因式分解。

成熟的矩阵指数算法通常采用 scaling and squaring（缩放后计算近似，再反复平方）配合 Padé 逼近及误差控制，而不是逐元素取指数或盲目截断泰勒级数。数值稳定性需由误差分析确认。

边界：矩阵指数始终存在且可逆，但矩阵对数不具有相同的无条件实数域存在性；非正规矩阵还可能产生短时强烈增长。

06 / 用标准库验证时间流的半群性质

from math import exp,isclose
def exp_jordan(t):
    c=exp(2*t)
    return ((c,t*c),(0.0,c))
def multiply(A,B):
    return tuple(tuple(sum(A[i][k]*B[k][j] for k in range(2))
                       for j in range(2)) for i in range(2))
lhs=multiply(exp_jordan(0.5),exp_jordan(0.7))
rhs=exp_jordan(1.2)
assert all(isclose(lhs[i][j],rhs[i][j],rel_tol=1e-14)
           for i in range(2) for j in range(2))
print("e^(sJ)e^(tJ)=e^((s+t)J): verified")

输出表明这个固定 Jordan 块的半群恒等式通过数值核验。它不是通用算法的精度保证，更不能用来推断任意不交换 A、B 的指数可相乘拆分。
