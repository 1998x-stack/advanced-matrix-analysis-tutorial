CHAPTER 23 / ADVANCED MATRIX ANALYSIS

张量代数基础：模-n 展开、模-n 积与张量秩

当数据天然是三维或更高维时，强行展平会打乱结构。本文定义张量的阶与形状、模-n 展开与模-n 积，说明它们如何把张量问题还原成矩阵问题，并区分 CP 秩与 Tucker 秩。

01 / 为什么矩阵不够用？

一个矩阵只有两个下标。但视频是 帧×高×宽×通道，脑电是 通道×时间×频率，推荐数据是 用户×物品×时间——它们天然有三个或更多下标。硬把它们展平成一个矩阵，等于选定了一个任意的方式把下标混在一起，往往会损坏可解释的结构。

先明确记号与边界。本章的“张量”指多维数组：一个 N 阶张量就是带 N 个下标的数组，元素记为 t_{i_1 i_2 … i_N}。这与多重线性代数里“张量=多重线性映射”的抽象定义不同；在数值计算中，把张量当作 ndarray 已足够。本课程默认实数域，写成 T∈R^{I_1×I_2×…×I_N}；复域结论需把转置换成共轭转置。

“阶（order）”就是下标个数；一个 N 阶张量有 N 个模（mode）。“阶”与“维”容易混：这里说“N 阶”指有 N 个模，而不是某个模的长度。

具体问题： 同一个 2×3×2 张量，沿不同模展平会得到形状、甚至秩都不同的矩阵（见下一节）。所以“展平”不是可逆的信息无损操作；张量代数要做的是：在展平与折叠之间建立一组可逆的、保持索引意义的规则。

02 / 从标量到高阶张量

阶数给出一个统一的语言：标量是 0 阶，向量 1 阶，矩阵 2 阶，更高就是 3、4……阶张量。记号上用花体 T 表示 3 阶及以上，粗体大写 A 表示 2 阶（矩阵），粗体小写 v 表示 1 阶（向量）。

按阶数组织的对象谱系（形状用 NumPy 惯例书写）
对象阶数形状元素记号示例
标量0()xx=5
向量1(n,)v_i[1,2,3]
矩阵2(m,n)a_{ij}[[1,2],[3,4]]
张量N(I₁,…,I_N)t_{i₁…i_N}2×3×2
别名与坑： shape=(n,) 是 1 阶；shape=(n,1) 是 2 阶（列向量矩阵），两者不可混。编程中张量就是 ndarray，阶数就是 ndim，每个模的长度就是 shape 的对应项。具体到数据：特征图常是 批×通道×高×宽（4 阶），多头注意力的输出也是张量。

03 / 模-n 展开：张量与矩阵的桥梁

要把已有矩阵工具（LU、QR、SVD）用到张量上，第一步是把张量变成矩阵。对 T∈R^{I_1×…×I_N}，模-n 展开 T_(n) 把所有“第 n 维固定、其余维自由”的纤维（fiber）按字典序排成行：

T(n)∈RIn×(I1⋯In−1In+1⋯IN)23.1

行数永远是第 n 维的大小 I_n，列数是所有其余维长度的乘积。用一个具体张量看：T∈R^{2×3×2}，两个 frontal slice 为

T(1)=(123789456101112)∈R2×623.2

同理，模-2 展开固定第二维，得 T_(2)∈R^{3×4}，其行为 [1,4,7,10]、[2,5,8,11]、[3,6,9,12]；模-3 展开得 T_(3)∈R^{2×6}，行为 [1,4,2,5,3,6]、[7,10,8,11,9,12]。

模的序号从 1 开始： 数学文献常用模-1/2/3，编程（NumPy）里下标从 0 开始。写代码时不要错位；上例的“模-1”对应 axis=0。

04 / 模-n 积：让矩阵沿着一个模作用

展开之后，自然的运算就是“让一个矩阵只沿着某一个模作用”。对一个 N 阶张量 T 和矩阵 U∈R^{J×I_n}，模-n 积 T ×_n U 的结果仍是一个 N 阶张量，只是第 n 维从 I_n 变成 J：

(T×nU)i1…j…iN=∑in=1Inti1…iNujin23.3

它和矩阵乘法的关系可以用展开一句话说完——这也是所有张量分解算法的基石：

Y=T×nU⟺Y(n)=UT(n)23.4

也就是说：先沿模 n 展开，左乘 U，再折回张量。模-n 积有几条常用性质：

  • 不同模可交换： T ×_m A ×_n B = T ×_n B ×_m A（m≠n）；
  • 相同模可合并： T ×_m A ×_m B = T ×_m (BA)；
  • 与向量缩并降阶： T ×̄_n v 把 N 阶降为 N−1 阶。
尺寸敏感： 模-n 积不是矩阵乘法，也不改变其他模的长度。U 的列数必须等于第 n 维的长度，而不是别的模；对应错模会得到形状看似合理但语义完全不同的结果。

05 / Kronecker 与 Khatri-Rao 积：连接展开与因子矩阵

第 19 章的 Kronecker 积 A⊗B 与 Khatri-Rao 积 A⊙B（列向 Kronecker）在张量分解里充当“展开—因子”矩阵之间的桥。先从概念上写下一个 3 阶张量的两种形式，它们分别是下一章 CP 与 Tucker 分解的展开表达式。

T(1)≈Adiag(λ)(C⊙B)T23.5
T(1)=AG(1)(C⊗B)T23.6

式 23.5 是 CP-ALS 算法的核心：A=[a_1,…,a_R]、λ=(λ_1,…,λ_R)；式 23.6 则是 Tucker 分解的形式，G 是核张量。Khatri-Rao 对应 CP，Kronecker 对应 Tucker——记住这个对应关系就不会混。

两种“老朋友”乘积在张量语境下的角色
积记号维度规则张量分解中的角色
Kronecker 积A⊗B(m×n)⊗(p×q) → (mp×nq)Tucker 展开 (C⊗B)
Khatri-Rao 积A⊙B(m×r)⊙(n×r) → (mn×r)CP 展开 (C⊙B)
尺寸提醒： ⊙ 要求两矩阵列数相同（都等于秩 R），⊗ 无此要求。列数不等时 ⊙ 未定义，不能强行相乘。

06 / 张量范数与两种秩

范数直接从矩阵推广。最常用的是 Frobenius 范数（所有元素平方和的平方根）：

‖T‖F=∑i1=1I1⋯∑iN=1INti1…iN223.7

它与模展开的关系很简单：‖T‖_F = ‖T_(n)‖_F，任一模展开都一样——这正是两个算例里的“平方和恒为 650”。张量的谱（算子）范数则是所有单位向量沿各模缩并后的最大绝对值，定义较重，实际更常用展开主奇异值来估计。

真正的陷阱在秩。矩阵的秩有唯一且良定义的概念；张量至少有两个不同的“秩”：

T=∑r=1Rar(1)∘⋯∘ar(N)23.8
rank(T(n))=Rn,Tucker秩=(R1,…,RN)23.9
  • CP 秩： 式 23.8 中最小的项数 R。精确计算它是 NP-hard；而且实数域与复数域上的秩可能不同，不能默认它们相等。
  • Tucker（多线性）秩： 式 23.9 中每个模展开的矩阵秩组成的 N 元组。它可以直接对 T_(n) 做 SVD 得到，计算廉价。
最容易错的一点： CP 秩是一个数，Tucker 秩是 N 个数，两者不可比较也不相等。一个张量的 Tucker 秩为 (2,2,2) 并不说明 CP 秩就是 2。

07 / 可复算算例：手写模展开

下面只用 Python 标准库，把 2×3×2 张量的模-1、模-2 展开写成嵌套列表推导，并验证：元素总和、平方和与 Frobenius 范数不随展开变化。

T = [[[1,7],[2,8],[3,9]], [[4,10],[5,11],[6,12]]]   # T[i][j][k]，形状 2×3×2
flat = [T[i][j][k] for i in range(2) for j in range(3) for k in range(2)]
print("sum=%d sq=%d frob=%.4f" % (sum(flat), sum(x*x for x in flat), sum(x*x for x in flat)**0.5))
T1 = [[T[i][j][k] for k in range(2) for j in range(3)] for i in range(2)]   # 模-1：行=i，列按 j 快、k 慢
T2 = [[T[i][j][k] for k in range(2) for i in range(2)] for j in range(3)]   # 模-2：行=j，列按 i 快、k 慢
print("T1=", T1); print("T2=", T2)

预期输出：sum=78 sq=650 frob=25.4951，以及 T1=[[1,2,3,7,8,9],[4,5,6,10,11,12]]、T2=[[1,4,7,10],[2,5,8,11],[3,6,9,12]]。核对要点： 两个展开的元素集合相同，故和、平方和、Frobenius 范数完全一致；差别只在索引排列。失败模式： 若把字典序循环的顺序写错（例如在模-1展开里把 k 放在 j 外层），列顺序会变成 [1,7,2,8,3,9]，与定义不符；这类错位不会报错，却会让后续分解结果完全错误。

T∈R^{2×3×2}，模-1展开 T_(1)∈R^{2×6}；元素总和 78，平方和 650。

该控件对三种模给出展开矩阵的形状：行数总是所选模的长度，列数是其余维乘积。默认状态无需脚本即可读出；键盘可切换选项。
